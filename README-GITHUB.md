# FlashCards

Веб-приложение для изучения с интервальным повторением (аналог Anki).

## Демо
[Открыть приложение](https://yourusername.github.io/flashcards/)

## Возможности
- 📚 Создание колод и карточек
- 🧠 Интервальное повторение (алгоритм SM-2)
- 📊 Статистика обучения
- 🔍 Поиск по карточкам
- 🏷️ Теги для организации
- 📤📥 Экспорт/импорт данных
- 💾 Работает офлайн (PWA)

## Использование
1. Создайте колоду
2. Добавьте карточки
3. Начните изучение
4. Оценивайте свои ответы

## Установка на телефон
1. Откройте приложение в Safari (iOS) или Chrome (Android)
2. Нажмите "Поделиться" → "На экран Домой"
3. Готово! Работает как обычное приложение

## Технологии
- Vanilla JavaScript
- CSS3 (Material Design)
- LocalStorage
- Service Worker (PWA)
