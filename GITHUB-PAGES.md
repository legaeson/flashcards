# 🚀 Как разместить на GitHub Pages

## Быстрая инструкция (5 минут)

### Шаг 1: Создать аккаунт
1. Откройте [github.com](https://github.com)
2. Нажмите **Sign up** (если нет аккаунта)
3. Зарегистрируйтесь

### Шаг 2: Создать репозиторий
1. Нажмите кнопку **"+"** в правом верхнем углу → **New repository**
2. Назовите репозиторий: `flashcards` (или любое имя)
3. Поставьте галочку **"Public"**
4. Нажмите **"Create repository"**

### Шаг 3: Загрузить файлы
1. На странице репозитория нажмите **"uploading an existing file"**
2. Перетащите **ВСЕ файлы** из папки:
   - index.html
   - style.css
   - app.js
   - manifest.json
   - service-worker.js
3. Нажмите **"Commit changes"**

### Шаг 4: Включить GitHub Pages
1. Перейдите в **Settings** (вкладка вверху)
2. Слева найдите **Pages**
3. В разделе **"Source"** выберите:
   - Branch: **main** (или **master**)
   - Folder: **/ (root)**
4. Нажмите **Save**
5. Подождите 1-2 минуты

### Шаг 5: Готово! 🎉
Ваша ссылка будет:
```
https://ваш-username.github.io/flashcards/
```

Откройте её на iPhone в Safari и добавьте на главный экран!

---

## Альтернатива: GitHub Desktop (если есть программа)

1. Скачайте [GitHub Desktop](https://desktop.github.com/)
2. File → New Repository
3. Name: `flashcards`
4. Скопируйте все файлы в созданную папку
5. Commit и Publish
6. На github.com включите Pages как в Шаге 4

---

## 💡 Плюсы GitHub Pages:
- ✅ Бесплатно навсегда
- ✅ Быстро работает
- ✅ Доступ с любого устройства
- ✅ Автоматическое обновление (загрузите новые файлы)
- ✅ Можно дать ссылку друзьям

## ⚠️ Важно:
Все данные (карточки, колоды) сохраняются **только в браузере на устройстве**. GitHub хранит только код приложения, не ваши данные.
