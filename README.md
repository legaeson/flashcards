# 📚 FlashCards - Аналог Anki для iPhone

Веб-приложение для эффективного изучения с интервальным повторением.

## 🚀 Как запустить на iPhone

### ✅ Способ 1: Прямо из файлов (САМЫЙ ПРОСТОЙ)

1. **Перенесите папку на iPhone:**
   - Через **AirDrop**: выберите папку на Mac → Поделиться → AirDrop на iPhone
   - Через **iCloud Drive**: скопируйте папку в iCloud, откройте на iPhone
   - Через мессенджер: отправьте файл `index.html` себе в Telegram/WhatsApp

2. **Откройте приложение:**
   - Откройте приложение **Файлы** на iPhone
   - Найдите файл `index.html`
   - Нажмите на него - откроется в Safari
   - Готово! Можно пользоваться! ✅

3. **Добавить на главный экран (опционально):**
   - Нажмите кнопку "Поделиться" (□↑) внизу Safari
   - Прокрутите вниз и выберите **"На экран «Домой»"**
   - Нажмите "Добавить"
   - Теперь приложение на главном экране как настоящее! 📱

### 🌐 Способ 2: Через локальный сервер

Если компьютер и iPhone в одной Wi-Fi:

1. На компьютере запустите `start-server.bat`
2. Узнайте IP адрес компьютера (показывается при запуске)
3. На iPhone откройте Safari и введите: `http://192.168.X.X:8000`
4. Добавьте на главный экран как в способе 1

### ☁️ Способ 3: Разместить онлайн (БЕСПЛАТНО)

Загрузите все файлы на GitHub Pages, Netlify или Vercel - откройте по ссылке с любого устройства!

## 🧠 Алгоритм интервального повторения

Используется модифицированный алгоритм **SM-2** (SuperMemo):

- **Снова** - показать через 1 минуту
- **Трудно** - показать через 10 минут
- **Хорошо** - показать через 1 день
- **Легко** - показать через 4 дня

Интервалы автоматически увеличиваются на основе ваших ответов.

## 💾 Хранение данных

Все данные хранятся локально в браузере (LocalStorage). Ничего не отправляется на сервер.

Регулярно делайте экспорт данных через настройки для резервного копирования!

## 📝 Использование

1. **Создайте колоду** - нажмите кнопку "+" на главном экране
2. **Добавьте карточки** - откройте колоду и добавьте карточки
3. **Начните изучение** - нажмите "Изучать" на колоде
4. **Оценивайте свои ответы** - чем точнее, тем лучше работает алгоритм

## 🎯 Советы

- Создавайте карточки небольшими порциями (10-20 в день)
- Будьте честны в оценках - это улучшит эффективность
- Учитесь каждый день, чтобы сохранить серию 🔥
- Регулярно делайте экспорт данных
- Используйте теги для организации больших колод

## 🔒 Приватность

- Все данные хранятся только на вашем устройстве
- Нет отправки данных на сервер
- Нет аналитики или трекинга
- Полный контроль над вашими данными
